# 课程生成器前端 PRD 对齐计划

## 目标

在不扩展后端产品范围的前提下，基于现有 REST API 重建 React 前端，使其对齐 PRD 的课程库、七阶段生成工作台与课程阅读器三类体验。

## 实施

1. 将 API 类型补全为课程、运行、产物、发布与可编辑文件，并定义统一的七阶段元数据。
2. 重建课程库和结构化建课表单，覆盖学习者、目标、范围、篇章、篇幅、预算、资料政策与补充资料。
3. 重建三栏工作台：阶段轨、产物工作区、人工审查面板；复用审批、返工、暂停和停止 API。
4. 用已发布版本与课程产物构建只读阅读器，提供目录、阅读进度、上一/下一章与 Markdown 下载。
5. 在独立分支运行前端构建与测试；用真实已生成课程在浏览器验收，再合并到 main。

## 边界

- 不创建新的后端业务流程或模型能力。
- 后端未提供运行列表时，课程库只展示可由课程与发布 API 得出的状态；运行细节在工作台地址中查看。
- 仅后端允许的课程文件可编辑，机器产物保留为只读证据。
